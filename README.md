# webots-python-curriculum

Материалы учебного курса по робототехнике в Webots, сделанного **по образу и подобию классического *Cyberbotics’ Robot Curriculum***:

[Cyberbotics’ Robot Curriculum (PDF)](https://upload.wikimedia.org/wikipedia/commons/3/3d/Cyberbotics%27_Robot_Curriculum.pdf)

Этот репозиторий — Python-версия курса. Основная канва, последовательность тем и учебные миры взяты из оригинального учебника, но примеры переписаны на Python и немного видоизменены. Все используемые миры взяты из оригинального курса.

Проект можно скопировать себе, открыть в Webots и позапускать примеры. Это не официальный курс Cyberbotics и не замена оригинальному учебнику, а его Python-адаптация для практики.

## Что нужно для запуска

- **Python 3.13**
- **Webots 2025a**
- Склонированный репозиторий
- Базовое понимание Python и желание разбираться в робототехнике

## Как начать

```bash
git clone https://github.com/<your-username>/webots-python-curriculum.git
cd webots-python-curriculum
```

Дальше открывайте нужный мир в Webots 2025a и запускайте соответствующий Python-контроллер. В каждой папке будет отдельное описание: что происходит, какие сенсоры/актуаторы используются и что нужно сделать.
